# reviews/

Review rounds happen after a version is complete (PLAYBOOK Phase 7). One folder per round: `round-N-<reviewer>/` containing:

- `brief.md` — the focused assignment (format: `BRIEF-TEMPLATE.md` in this folder)
- `findings.md` — the reviewer's structured output
- `accepted.md` — what the owner accepted and why (written after arbitration)

Reviewers never edit material files directly and never receive copies of the project. A round with nothing accepted freezes the version (endpoint rule).
