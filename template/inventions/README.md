# inventions/

The AI's own methods (Phase 4). One file per invention: `INV-XX-<slug>.md`.

Each must state:

- knowledge basis — which methods and sources it builds on
- the full recipe with numbers (every load-bearing assumption labeled `ai_proposal`)
- falsifiers for the load-bearing claims
- safety notes (same standard as method action plans)

An invention is a testable proposal, not a claim of novelty, patentability, or performance.
