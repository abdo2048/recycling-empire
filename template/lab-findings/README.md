# lab-findings/ — team results (first-class evidence)

One file per experiment: `YYYY-MM-DD-<short-name>.md` containing: who ran it, the protocol reference (method M-XX, section 5 item), what was measured, results with units, deviations from the planned protocol, photos or links.

Lab findings justify a new review round (PLAYBOOK endpoint rule) and are cited like any source, with the label `measured`.
